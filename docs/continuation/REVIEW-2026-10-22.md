## Checked, and not filed as defects

- Doctrine sentence in `server/src/network/logic.ts` is exactly: "No tax classification is asserted for NTE; working position held pending written counsel confirmation." `AGENTS.md` matches it. The scan roots do not contain `non-grantor` or `irrevocable`.
- `BOOTSTRAP_ADMIN_SECRET` unset, missing, or wrong returns 403 and does not insert. A second admin returns 409. The error text does not echo the secret. `env.ts` does not print `INVITE_CODE` or `JWT_SECRET`. Production boot throws when either is missing.
- Download `?token=` accepts only a 60-second grant whose `attachmentId` matches the route. A session JWT in the query is refused. A grant presented as a bearer session is refused. The grant route checks record access before signing.
- Desk lists filter `?entity=` with a bound parameter from the closed list. Another account's rows are not returned. `SYSTEM_ADMIN` can read other accounts' desk rows and `projectForWrite` still refuses a write into another account. A second account may approve a release when it has the proposal id and hash; the proposer cannot. That is the rule in `AGENTS.md`.
- Registry import defaults to dry-run, refuses an unknown `entityId`, and refuses evidence status `VERIFIED` or `SYSTEM_RECORDED`. Revenue rejects a missing evidence link, a negative figure, an estimate flag, and a net that is not gross minus refunds within 0.001. An empty summary is `no evidence recorded` with null amounts.
- `configureIntegration` rejects a top-level secret key and stores only a local label. Nested secret fields are not written.
- Committed fixtures use `test-secret-not-used-anywhere-real` and `test-invite-code`. `server/.env.example` has names and empty values.
